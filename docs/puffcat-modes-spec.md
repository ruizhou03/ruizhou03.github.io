# 百变小咪 · 新模式设计稿（2026-11-15）

目的：在「经典模式」之外加几套只有我们有的机制——既让游戏更好玩，也让它从「同款」变成「同类型」（降低和原版规则一一对应的风险）。
经典模式保持现状不动；新东西都做成可选模式，一个个上线。

上线顺序（建议）：① 百变规则 → ② 2v2 组队 → ③ 炸毛值（先当一条百变规则试水）→ ④ 角色猫。

## ① 百变规则（「今日规则」）

桌上公开摆两张规则牌：**生效中** 1 张 + **预告** 1 张（大家都看得到下一条是什么，可以提前算计）。

怎么变：
- 牌堆里加 4 张新行动牌「百变」：打出 → 预告那条翻成生效，再翻一张新的预告。可以被作废。
- 不靠计时 / 自动轮换：什么时候变规则由玩家决定，才有策略（明知下一条对自己有利就去打「百变」）。

规则池（第一批 10 条，引擎已有开关的标 ★，其余要新写）：

| 名字 | 效果 |
|---|---|
| 不叠锅 ★ | 甩锅不叠加，被甩锅最多摸 2 张 |
| 暗塞 ★ | 塞回炸毛猫谁也看不出高低 |
| 明塞 | 塞回炸毛猫报出第几张 |
| 摸底 | 结束回合时从牌堆最底下摸 |
| 逆行 | 出牌方向反过来（生效 / 失效时各转一次） |
| 静音 | 不能出「作废」 |
| 千里眼 | 窥探看 5 张 |
| 双响 | 每次摸牌摸 2 张（第一张是炸毛猫就停） |
| 慷慨 | 被索要时由索要的人自己挑 |
| 顺毛 | 炸毛值规则（见 ③）：第一次炸毛不出局 |

机器猫：每条规则对机器猫是「规则开关」，判断里按当前规则走；高手推演时也照当前 + 预告规则模拟。每条规则加进训练（对手桌照第二次重训的混桌做法）。

待定：规则池要不要能在设置里勾掉某几条；「百变」张数随人数变不变。

## ② 2v2 组队（4 人）

- 座位：队友坐对面（0、2 一队，1、3 一队），出牌顺序上两队交替。
- 胜负：一队全部出局，另一队赢（只剩一人也算赢）。
- 队友共享（用户 2026-11-15 定）：
  - 窥探 / 改命看到的顶上三张，队友也看得到；
  - 自己摸到炸毛猫、手里又没有逗猫棒时，队友有一个短窗口可以出自己的逗猫棒救他；救下后由被救的人把炸毛猫塞回去；
  - 队友之间**看不到**对方具体有什么牌（只照常看到张数）。
- 其他：
  - 对队友出「索要」= 向队友要牌（队友挑一张给），等于传牌，允许；
  - 甩锅能甩给队友（一般没人这么干，不禁止）；
  - 出局的人可以看队友的手牌（观战）。

待定：要不要给队友一套只有队友看得到的快捷暗号（「顶上危险」「我有作废」「救我」）；6 人 3v3 以后再说。

## ③ 炸毛值

- 摸到炸毛猫、没有逗猫棒：不直接出局，而是**炸毛一格**（头像上一根竖起的毛），炸毛猫由他塞回牌堆；满两格才出局。
- 逗猫棒照旧：摸到时用掉、不涨格子。
- 先当百变规则「顺毛」上线试手感，再决定要不要单独成模式。

待定：满格是 2 还是 3；炸毛猫数量要不要少一只（不然局会拖长）。

## ④ 角色猫

开局每人选（或随机发）一只角色猫，各有一个被动 / 一次性技能，桌上头像就是这只猫：

| 角色 | 技能 |
|---|---|
| 胆小猫 | 每局一次：免费偷看牌堆顶 1 张 |
| 胖橘 | 开局多发 1 张手牌 |
| 黑猫 | 第一次被索要 / 偷牌时躲过 |
| 奶牛猫 | 每局一次：被甩锅时少摸 1 张 |
| 三花 | 打两张一样的猫牌时，可以先看对方一张再决定偷哪张 |
| 狸花 | 每局一次：作废可以当作「不能被作废」打出 |

工作量最大：每个角色都要平衡 + 训练机器猫；也是以后最自然的变现点（角色 / 皮肤）。
