# 百变小咪 · 新模式设计稿（2026-11-15）

目的：在「经典模式」之外加几套只有我们有的机制——既让游戏更好玩，也让它从「同款」变成「同类型」（降低和原版规则一一对应的风险）。
经典模式保持现状不动；新东西都做成可选模式，一个个上线。

上线顺序（2026-11-15 用户定）：① 百变规则 → ② 2v2 组队 → ③ 角色猫 → ④ 炸毛值。

## ① 百变规则

（2026-11-15 用户定：用甲的样子，但**不要预告**，改成抽的）

- 桌上固定位置（牌堆下面）一张横放的规则牌，标题写「百变规则」+ 这条的名字和一句说明；开局没有规则，那里空着 / 淡着。
- 牌堆里加 4 张新行动牌「百变」：打出（没被作废）→ 从「百变牌堆」里随机抽一张规则，抽到什么就是什么，换掉原来那条。抽的样子（转盘 / 小牌堆翻牌）出几版给用户挑。
- 规则抽完了把用过的洗回去（当前这条除外）。
- 张数（2026-11-15 用户：百变只是抽奖、本身不如跳过好用）：开局人人额外白送一张（不占那 4 张）；牌堆里标准 / 快局按人数 2–7 张（4 人 3 张）。牌号每副 10 张。

| 九命 | 摸到炸弹猫又没逗猫棒，不出局，再像用逗猫棒一样自己挑位置把炸弹猫塞回去（每次抽到这条，每人最多一次；2026-11-26 起，以前是随机塞） |

## ② 组队（2026-11-18 起不止 2v2）

- 队形（2026-11-18 用户）：每队人数相等，不做以少打多。设置单（2026-11-19 用户挑「丙」）先选几个人玩（4–9，5、7 没有等分法灰着）、再选怎么分：4 人 2v2；6 人 3v3 / 2v2v2；8 人 4v4 / 2v2v2v2；9 人 3v3v3。联机大厅同样两行（人数 / 分法）。不做人数不均等（「戊」）：联机凑不齐就点空位加机器猫。
- 座位排法（设置单二选一）：同队坐一起（一圈分成几段，我在自己那段里排第几随机）/ 随机打乱（每局整圈随机，可能挨着、被拆开或一人隔一人）。
- 队友共享情报、能救队友、能对队友出牌：组队自带，不进设置单。
- 桌面「围桌一圈」（2026-11-18 用户定）：所有人（包括我）都坐在桌沿上，我在底边靠左；其余按出牌顺序逆时针排在右边 → 顶边 → 左边三条直边上，**头像永远不放在拐角**（拐角特别丑）。摸牌 / 出牌键往右让开我。手机横屏时顶边只在中间那段坐人（左右是比分条和工具键）。
- 队伍区分：只看**头像底色**（把头像自带的圆底换成队色，「中」档深浅：藏蓝 / 松绿 / 赭橙 / 藕粉，我这队永远藏蓝）；外圈只表示状态（轮到谁朱红、能指谁金、在看谁墨），不叠两圈。
- 灯带：平时绕桌沿的三颗彗星换成正在出牌那队的颜色；出牌的金 / 紫光带、瞄准线照旧。
- 左上角保留招牌（2026-11-18 用户：不放比分条），游戏里也用主页那套笔画艺术字。
- 方向箭头（围桌一圈）：不放（2026-11-18 用户在四版里挑了「不放」）——方向靠桌沿彗星，轮到谁看红圈。
- 出局头像（组队）：垫实心纸色底（灯带不穿过），只褪掉大半颜色，队色底仍认得出。
- 结算：标题一律「排行榜」（不写谁赢了）；每一队按名次挂金 / 银 / 铜牌（赢的队都是金牌），同队排在一起、队内按个人名次排。右边写个人名次（2026-11-19）：按第几个出局定，第一个出局的垫底；赢的时候还活着的人并列第 1。
- 联机（2026-11-18 上线）：大厅规则卡多「玩法 / 队形 / 座位」三行（房主定）；座位按顺序分段就是分队（前 k 个一队……），每段一块队色底板；想换队就坐到别队空位，房主可「随机分队」；必须正好坐满队形人数才能开。开局「随机打乱」时服务器再洗座次（队不变）。救队友弹「递棒」提示（同时问、先到先得，限时到了 = 没救成）；出局的人自动坐到还活着的队友身后，能看队友手牌（不受「观战能看我的牌」开关限制）；房间战绩里赢的那队人人算赢。
- 救队友（2026-11-19 改成同时问）：摸到炸弹猫又没逗猫棒，只要还有活着的队友，就当众喊「救我！」，所有活着的队友头上同时冒会动的省略号（不管有没有逗猫棒，动画前半段永远一样）。只有手里有逗猫棒的队友弹窗（「不救」/ 绿色「救！」，绿色随倒计时往左缩、露出灰底，到点没救 = 没救成；限时和作废窗口一样长：联机 10 秒局 3 秒、其余 5 秒；单机 3 秒（10 秒局 2 秒，2026-11-19 用户：单机作废时间缩短））；谁先点「救」用谁的，晚到的按过时拒掉、逗猫棒不扣，弹窗里演「被抢先」：我的逗猫棒收回变灰，他的头像在上方冒出来、甩出逗猫棒转一圈落到炸弹猫上，落点炸开金光、炸弹猫停住缩回，弹窗淡出。弹窗里逗猫棒不画连线：自己往队友那边探身、队友身后一圈金光一起一伏（2026-11-19 用户在四版里挑的丙）；炸弹猫整张乱抖、一阵阵冒红光。不救不出任何事件。有人救：他的省略号变「接着！」、别人的收回；没人救（没有 / 不肯 / 到点）：省略号收回、出局，且最早要等机器猫想作废的最长时间（约 1.25 秒）才判，没人有和有人不肯看起来一样。有逗猫棒的机器猫队友想救的时间和想作废一样（单机 0.5–1.1 秒、联机 0.8 秒），真人在这之前点也能抢先。
- 「别救我」开关（2026-11-19 用户）：组队局我头像左上角一枚小逗猫棒，点一下变灰划红线 = 别救我，再点改回；活着随时能改，每局开局默认可以救。同队的人开了，他头像上也挂这枚划线逗猫棒（只同队看得到）。开着时炸毛：谁都不问（同队那边他喊「别救我！」、队友不冒省略号），照样等够约 1.25 秒再出局；对手那边看到的仍是喊「救我！」、队友冒省略号、没救成——和「队友都没逗猫棒」一模一样。联机：开关是一步 move（type noHelp），只存进状态、不进日志；服务器只把同队的开关和 refused 发给同队。机器猫自己不开这个开关。
- 平衡（2026-11-18，普通机器猫各 600 局）：各队形、两种坐法胜率都在均等的抽样误差内；三队以上机器猫自由甩锅时优先冲活着人多的那队。

## ③ 角色猫

开局每人抽一只角色猫（大家都看得到），**整局有效、全部自动、每只一句话一个效果**（2026-11-15 用户：简单直接，平衡不了就换方向，别打补丁）。
2026-11-18 改名（以前「三花 / 奶牛猫 / 狸花」和猫牌同名、「胖橘」≈橘猫牌，说起来分不清是牌还是人）：角色 = 一只带道具的猫，名字统一「××猫」。代码 id 不变。

| 角色（id） | 技能 | 形象 |
|---|---|---|
| 胆小猫（timid） | 被甩锅，先偷看牌堆顶 3 张 | 缩在纸箱里、冒汗 |
| 贪吃猫（fat） | 出索要，对方要给 2 张 | 捧着红碗、碗里两条鱼（用户挑甲） |
| 影子猫（shadow） | 两张偷牌指不到它 | 月牙下的黑猫、一对黄眼睛 |
| 扛锅猫（cow） | 被甩锅只摸 1 张（再甩出去下家 1+2=3） | 奶牛花色、头上倒扣一口锅 |
| 百搭猫（calico） | 猫牌一到手就变万能猫（同百变「百搭」：任意两只 = 一对、三只 = 三张、五只 = 五种各一张；手牌里画成万能猫，摸进来翻一下变身，出手半路翻回原样） | 三花抱拼布、捏针 |
| 截胡猫（tabby） | 作废成功，顺走被作废那人一张 | 身后一圈禁止符号、举爪「停」（用户挑丙） |

## ④ 炸毛值

- 摸到炸弹猫、没有逗猫棒：不直接出局，而是**炸毛一格**（头像上一根竖起的毛），炸弹猫由他塞回牌堆；满两格才出局。
- 逗猫棒照旧：摸到时用掉、不涨格子。
- 以后可以先当一条百变规则「顺毛」试手感，再决定要不要单独成模式。

待定：满格是 2 还是 3；炸弹猫数量要不要少一只（不然局会拖长）。
