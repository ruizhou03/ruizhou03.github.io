# 百变小咪 · 新模式设计稿（2026-11-15）

目的：在「经典模式」之外加几套只有我们有的机制——既让游戏更好玩，也让它从「同款」变成「同类型」（降低和原版规则一一对应的风险）。
经典模式保持现状不动；新东西都做成可选模式，一个个上线。

上线顺序（2026-11-15 用户定）：① 百变规则 → ② 2v2 组队 → ③ 角色猫 → ④ 炸毛值。

## ① 百变规则

（2026-11-15 用户定：用甲的样子，但**不要预告**，改成抽的）

- 桌上固定位置（牌堆下面）一张横放的规则牌，标题写「百变规则」+ 这条的名字和一句说明；开局没有规则，那里空着 / 淡着。
- 牌堆里加 4 张新行动牌「百变」：打出（没被作废）→ 从「百变牌堆」里随机抽一张规则，抽到什么就是什么，换掉原来那条。抽的样子（转盘 / 小牌堆翻牌）出几版给用户挑。
- 规则抽完了把用过的洗回去（当前这条除外）。
- 张数（2026-11-15 用户：百变只是抽奖、本身不如跳过好用）：开局人人额外白送一张（不占那 4 张）；牌堆里标准 / 快局按人数 2–7 张（4 人 3 张）。牌号每副 10 张。

规则（2026-11-15 用户：不叠锅 / 暗塞 / 千里眼 / 慷慨太弱 → 换成九命 / 掀顶 / 烫手 / 双猫急救；之后又按实测删掉静音 / 双猫急救 / 逆行，现为 5 条：九命 / 掀顶 / 明塞 / 摸底 / 烫手）：

| 名字 | 效果 |
|---|---|
| 九命 | 摸到炸毛猫又没逗猫棒，不出局（每人一局一次），炸毛猫随机塞回去 |
| 掀顶 | 牌堆最上面那张一直翻开，大家都看得到 |
| 明塞 | 塞回炸毛猫报出第几张 |
| 摸底 | 结束回合时从牌堆最底下摸 |
| 逆行 | 出牌方向反过来（抽到 / 换走时各转一次） |
| 静音 | 不能出「作废」 |
| 烫手 | 每个人的回合都要摸两张 |
| 双猫急救 | 摸到炸毛猫又没逗猫棒，交出一对一样的猫牌顶上 |

桌上样子（用户定）：百变牌 = 甲 1 · 魔法棒（五彩描边 + 斜光 + 深紫金字）；抽规则 = 乙 · 转盘；规则牌第一次抽到才出现。

机器猫：view 里给的是「生效规则」+ flux / nineUsed；摸底时算底牌的风险；九命没用过 / 双猫急救手里有对子时当作「有逗猫棒」；掀顶时顶牌进 known；「百变」牌按牌值打，静音手里有作废或攒了两张百变时先打。

## ② 2v2 组队（4 人）

- 界面（用户定）：队友头像放在底下一行——我的头像、摸牌、出牌右边那块空位；同队用同样的底色或名字旁的标识，两队各别一枚不同的队伍徽章 / 装饰（出几版挑）。

- 座位：队友坐对面（0、2 一队，1、3 一队），出牌顺序上两队交替。
- 胜负：一队全部出局，另一队赢（只剩一人也算赢）。
- 队友共享（用户 2026-11-15 定）：
  - 窥探 / 改命看到的顶上三张，队友也看得到；
  - 自己摸到炸毛猫、手里又没有逗猫棒时，队友有一个短窗口可以出自己的逗猫棒救他；救下后由被救的人把炸毛猫塞回去；
  - 队友之间**看不到**对方具体有什么牌（只照常看到张数）。
- 其他：
  - 对队友出「索要」= 向队友要牌（队友挑一张给），等于传牌，允许；
  - 甩锅能甩给队友（一般没人这么干，不禁止）；
  - 出局的人可以看队友的手牌（观战）。

待定：要不要给队友一套只有队友看得到的快捷暗号（「顶上危险」「我有作废」「救我」）；6 人 3v3 以后再说。

## ③ 角色猫

开局每人随机发一只角色猫（大家都看得到谁是什么猫），各有一个技能。**2026-11-15 提案：技能全部自动触发、不加按钮**（操作不变、新手无负担），每只的技能都是「一局一次」或很小的常驻加成：

| 角色 | 技能（自动） | 什么时候生效 |
|---|---|---|
| 胆小猫 | 第一次轮到他时，自动偷看牌堆顶 1 张 | 一局一次 |
| 胖橘 | 开局多发 1 张手牌 | 开局 |
| 黑猫 | 第一次被索要时溜走，什么都不给（2026-11-15 平衡：原来偷 / 点名也躲，胜率 1.31） | 一局一次 |
| 奶牛猫 | 第一次被甩锅时，少摸 1 张 | 一局一次 |
| 三花 | 任意两只不同的猫牌也能当一对用来偷牌 | 常驻 |
| 狸花 | 开局多一张「作废」；他打出的作废都不能再被作废（2026-11-15 平衡：原来只有第一张，胜率 0.83） | 常驻 |

桌上：头像换成这只角色猫，头像旁一个小技能图标，用掉了变灰；点头像看技能说明。
平衡（12000 局普通机器猫，1.00 = 均等）：狸花 1.01 / 黑猫 1.01 / 胖橘 0.95 / 胆小猫 1.04 / 奶牛猫 1.00 / 三花 0.99。
待用户定：要不要能自己挑角色（还是随机）；单机先做，联机后做。

## ④ 炸毛值

- 摸到炸毛猫、没有逗猫棒：不直接出局，而是**炸毛一格**（头像上一根竖起的毛），炸毛猫由他塞回牌堆；满两格才出局。
- 逗猫棒照旧：摸到时用掉、不涨格子。
- 以后可以先当一条百变规则「顺毛」试手感，再决定要不要单独成模式。

待定：满格是 2 还是 3；炸毛猫数量要不要少一只（不然局会拖长）。
