# 百变小咪 · 新模式设计稿（2026-11-15）

目的：在「经典模式」之外加几套只有我们有的机制——既让游戏更好玩，也让它从「同款」变成「同类型」（降低和原版规则一一对应的风险）。
经典模式保持现状不动；新东西都做成可选模式，一个个上线。

上线顺序（2026-11-15 用户定）：① 百变规则 → ② 2v2 组队 → ③ 角色猫 → ④ 炸毛值。

## ① 百变规则

（2026-11-15 用户定：用甲的样子，但**不要预告**，改成抽的）

- 桌上固定位置（牌堆下面）一张横放的规则牌，标题写「百变规则」+ 这条的名字和一句说明；开局没有规则，那里空着 / 淡着。
- 牌堆里加 4 张新行动牌「百变」：打出（没被作废）→ 从「百变牌堆」里随机抽一张规则，抽到什么就是什么，换掉原来那条。抽的样子（转盘 / 小牌堆翻牌）出几版给用户挑。
- 规则抽完了把用过的洗回去（当前这条除外）。
- 张数（2026-11-15 用户：百变只是抽奖、本身不如跳过好用）：开局人人额外白送一张（不占那 4 张）；牌堆里标准 / 快局按人数 2–7 张（4 人 3 张）。牌号每副 10 张。

规则（2026-11-15 用户：不叠锅 / 暗塞 / 千里眼 / 慷慨太弱 → 换成九命 / 掀顶 / 烫手 / 双猫急救；之后又按实测删掉静音 / 双猫急救 / 逆行，现为 5 条：九命 / 掀顶 / 明塞 / 摸底 / 烫手；用户又要回静音、双猫急救（改成任意一对一样的牌，功能牌也行），现为 7 条）：

| 名字 | 效果（现行，2026-11-15 用户定名定文） |
|---|---|
| 九命 | 摸到炸毛猫又没逗猫棒，不出局，炸毛猫随机塞回去（每次抽到这条，每人最多一次） |
| 透视 | 牌堆最上面那张一直翻开 |
| 火眼 | 塞回去的炸毛猫大家都看得到在第几张 |
| 摸底 | 结束回合改从牌堆最底下摸；「抽底」牌这时变成「抽顶」 |
| 烫手 | 每个人的回合一开始就像被甩了一次锅（要摸两次；这时再甩锅照常叠加，下家摸 4 次；跳过顶掉一次），立刻生效（2026-11-15 晚 用户定「套一层甩锅」，以前烫手给的两次不算被甩锅、甩锅等于白出） |
| 静默 | 不能出「作废」 |
| 急救 | 摸到炸毛猫又没逗猫棒，交出任意一对一样的牌顶上，炸毛猫随机塞回去（每人最多一次） |

（逆行已删，代码留着读旧存档。）

桌上样子（用户定）：百变牌 = 甲 1 · 魔法棒（五彩描边 + 斜光 + 深紫金字）；抽规则 = 乙 · 转盘；规则牌第一次抽到才出现。

机器猫：view 里给的是「生效规则」+ flux / nineUsed；摸底时算底牌的风险；九命没用过 / 双猫急救手里有对子时当作「有逗猫棒」；掀顶时顶牌进 known；「百变」牌按牌值打，静音手里有作废或攒了两张百变时先打。

## ② 组队（2026-11-18 起不止 2v2）

- 队形（2026-11-18 用户）：每队人数相等，不做以少打多。设置单可选 2v2 / 3v3 / 4v4 / 2v2v2（引擎另支持 2v2v2v2、3v3v3，界面先不开）。人数跟着队形定。
- 座位排法（设置单二选一）：同队坐一起（一圈分成几段，我在自己那段里排第几随机）/ 随机打乱（每局整圈随机，可能挨着、被拆开或一人隔一人）。
- 队友共享情报、能救队友、能对队友出牌：组队自带，不进设置单。
- 桌面「围桌一圈」（2026-11-18 用户定）：所有人（包括我）都坐在桌沿上，我在底边靠左；其余按出牌顺序逆时针排在右边 → 顶边 → 左边三条直边上，**头像永远不放在拐角**（拐角特别丑）。摸牌 / 出牌键往右让开我。手机横屏时顶边只在中间那段坐人（左右是比分条和工具键）。
- 队伍区分：只看**头像底色**（把头像自带的圆底换成队色，「中」档深浅：藏蓝 / 松绿 / 赭橙 / 藕粉，我这队永远藏蓝）；外圈只表示状态（轮到谁朱红、能指谁金、在看谁墨），不叠两圈。
- 灯带：平时绕桌沿的三颗彗星换成正在出牌那队的颜色；出牌的金 / 紫光带、瞄准线照旧。
- 左上角保留招牌（2026-11-18 用户：不放比分条），游戏里也用主页那套笔画艺术字。
- 方向箭头（围桌一圈）：不放（2026-11-18 用户在四版里挑了「不放」）——方向靠桌沿彗星，轮到谁看红圈。
- 出局头像（组队）：垫实心纸色底（灯带不穿过），只褪掉大半颜色，队色底仍认得出。
- 结算：标题一律「排行榜」（不写谁赢了）；每一队按名次挂金 / 银 / 铜牌（赢的队都是金牌），同队排在一起。
- 联机（2026-11-18 上线）：大厅规则卡多「玩法 / 队形 / 座位」三行（房主定）；座位按顺序分段就是分队（前 k 个一队……），每段一块队色底板；想换队就坐到别队空位，房主可「随机分队」；必须正好坐满队形人数才能开。开局「随机打乱」时服务器再洗座次（队不变）。救队友弹「递棒」提示、限时到了 = 救；出局的人自动坐到还活着的队友身后，能看队友手牌（不受「观战能看我的牌」开关限制）；房间战绩里赢的那队人人算赢。
- 救队友：几个队友都有逗猫棒时，按出牌顺序离被炸的人最近的先问，不救就问下一个。
- 平衡（2026-11-18，普通机器猫各 600 局）：各队形、两种坐法胜率都在均等的抽样误差内；三队以上机器猫指定甩锅时优先冲活着人多的那队。

以下为 2v2 时期（2026-11-15）的记录：

- 座位（2026-11-15 用户改）：队友和我出牌顺序挨着——我是队友的上家或下家（开局随机），不再两队交替。桌上整圈逆时针：队友是我下家时我左下、队友右下；队友是我上家时队友左下、我右下；上排两个对手之间有方向小箭头。
- 机器猫：下家是队友时普通甩锅不甩给他（只用指定甩锅甩对手）、改命多垫一张安全牌给他；塞炸毛猫不特意避开（试过往下挪一张，4000 局反而少赢 6%）。
- 胜负：一队全部出局，另一队赢（只剩一人也算赢）。
- 队友共享（用户 2026-11-15 定）：
  - 窥探 / 改命看到的顶上三张，队友也看得到；改命时队友看着他怎么排（三张正面摊开、排好后看着每张挪到新位置再扣回去），只是不能动（2026-11-18）；
  - 塞回炸毛猫的位置队友也知道（开缝开在真实那一张，牌堆正上方挂一枚小标签几秒（自己挑位置塞的也挂；靠后的说「倒数第 N 张 / 最后一张」，最上面说「最上面」；随机塞的挂一枚同样式的「随机」（2026-11-18 用户挑的丁的样子 + 写「随机」）））（2026-11-18）；
  - 自己摸到炸毛猫、手里又没有逗猫棒时，队友有一个短窗口可以出自己的逗猫棒救他；救下后由被救的人把炸毛猫塞回去；
  - 队友之间**看不到**对方具体有什么牌（只照常看到张数）。
- 其他：
  - 对队友出「索要」= 向队友要牌（队友挑一张给），等于传牌，允许；机器猫队友挑最有用的给，有两根以上逗猫棒时直接给一根（最后一根自己留着）（2026-11-18）；
  - 甩锅能甩给队友（一般没人这么干，不禁止）；
  - 出局的人可以看队友的手牌（观战）。
- 桌上（2026-11-18 用户）：队友头像和我的头像对齐在同一水平线（名字挂在头像下不占位）、整个座位往里收；别人抽队友的牌时那一小扇牌背摊在队友头像上方（不压我的手牌）；全局（各玩法）我自己头像右上角也挂手牌数。
- 救队友的提示（2026-11-18 用户挑甲「递棒」）：桌子蒙一层宣纸色，左边炸毛的队友（头像发抖、背后竖着炸毛猫），右边我发金光的逗猫棒，中间朱红虚线弧箭头；「不救 / 救！」，点逗猫棒也算救，到点没选 = 救。

待定：要不要给队友一套只有队友看得到的快捷暗号（「顶上危险」「我有作废」「救我」）；6 人 3v3 以后再说。

## ③ 角色猫

开局每人随机发一只角色猫（大家都看得到），**整局有效、全部自动、每只一句话一个效果**（2026-11-15 用户：简单直接，平衡不了就换方向，别打补丁）：

| 角色 | 技能 |
|---|---|
| 胆小猫 | 被甩锅时先偷看牌堆顶上 3 张 |
| 胖橘 | 他出「索要」，对方要给两张 |
| 黑猫 | 两张偷牌对他无效（也不能指他） |
| 奶牛猫 | 被甩锅永远只摸 1 张 |
| 三花 | 任意两只猫算一对、任意三只算三张 |
| 狸花 | 作废成功时，叼走被作废那人一张牌 |

桌上：头像左上角一枚小猫头（按头像大小缩放），点它弹技能说明。
平衡（12000 局普通机器猫，1.00 = 均等）：狸花 1.09 / 黑猫 1.08 / 奶牛猫 1.03 / 胖橘 0.93 / 三花 0.94 / 胆小猫 0.92。
单机已上线，联机后做。

## ④ 炸毛值

- 摸到炸毛猫、没有逗猫棒：不直接出局，而是**炸毛一格**（头像上一根竖起的毛），炸毛猫由他塞回牌堆；满两格才出局。
- 逗猫棒照旧：摸到时用掉、不涨格子。
- 以后可以先当一条百变规则「顺毛」试手感，再决定要不要单独成模式。

待定：满格是 2 还是 3；炸毛猫数量要不要少一只（不然局会拖长）。
