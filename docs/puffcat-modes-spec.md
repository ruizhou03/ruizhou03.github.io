# 百变小咪 · 新模式设计稿（2026-11-15）

目的：在「经典模式」之外加几套只有我们有的机制——既让游戏更好玩，也让它从「同款」变成「同类型」（降低和原版规则一一对应的风险）。
经典模式保持现状不动；新东西都做成可选模式，一个个上线。

上线顺序（2026-11-15 用户定）：① 百变规则 → ② 2v2 组队 → ③ 角色猫 → ④ 炸毛值。

## ① 百变规则

（2026-11-15 用户定：用甲的样子，但**不要预告**，改成抽的）

- 桌上固定位置（牌堆下面）一张横放的规则牌，标题写「百变规则」+ 这条的名字和一句说明；开局没有规则，那里空着 / 淡着。
- 牌堆里加 4 张新行动牌「百变」：打出（没被作废）→ 从「百变牌堆」里随机抽一张规则，抽到什么就是什么，换掉原来那条。抽的样子（转盘 / 小牌堆翻牌）出几版给用户挑。
- 规则抽完了把用过的洗回去（当前这条除外）。

第一批规则（8 条；「双响」「顺毛」先不放）：

| 名字 | 效果 |
|---|---|
| 不叠锅 | 甩锅不叠加，被甩锅最多摸 2 张 |
| 暗塞 | 塞回炸毛猫谁也看不出高低 |
| 明塞 | 塞回炸毛猫报出第几张 |
| 摸底 | 结束回合时从牌堆最底下摸 |
| 逆行 | 出牌方向反过来（抽到 / 换走时各转一次） |
| 静音 | 不能出「作废」 |
| 千里眼 | 窥探看 5 张 |
| 慷慨 | 被索要时由索要的人从他扣着的牌里抽 |

机器猫：view 里给的是「生效规则」（基本规则 + 百变那条叠上去），大部分判断自动跟着走；摸底时算底牌的风险、千里眼多记两张；「百变」牌按牌值打（可调参）。

## ② 2v2 组队（4 人）

- 界面（用户定）：队友头像放在底下一行——我的头像、摸牌、出牌右边那块空位；同队用同样的底色或名字旁的标识，两队各别一枚不同的队伍徽章 / 装饰（出几版挑）。

- 座位：队友坐对面（0、2 一队，1、3 一队），出牌顺序上两队交替。
- 胜负：一队全部出局，另一队赢（只剩一人也算赢）。
- 队友共享（用户 2026-11-15 定）：
  - 窥探 / 改命看到的顶上三张，队友也看得到；
  - 自己摸到炸毛猫、手里又没有逗猫棒时，队友有一个短窗口可以出自己的逗猫棒救他；救下后由被救的人把炸毛猫塞回去；
  - 队友之间**看不到**对方具体有什么牌（只照常看到张数）。
- 其他：
  - 对队友出「索要」= 向队友要牌（队友挑一张给），等于传牌，允许；
  - 甩锅能甩给队友（一般没人这么干，不禁止）；
  - 出局的人可以看队友的手牌（观战）。

待定：要不要给队友一套只有队友看得到的快捷暗号（「顶上危险」「我有作废」「救我」）；6 人 3v3 以后再说。

## ③ 角色猫

开局每人选（或随机发）一只角色猫，各有一个被动 / 一次性技能，桌上头像就是这只猫：

| 角色 | 技能 |
|---|---|
| 胆小猫 | 每局一次：免费偷看牌堆顶 1 张 |
| 胖橘 | 开局多发 1 张手牌 |
| 黑猫 | 第一次被索要 / 偷牌时躲过 |
| 奶牛猫 | 每局一次：被甩锅时少摸 1 张 |
| 三花 | 打两张一样的猫牌时，可以先看对方一张再决定偷哪张 |
| 狸花 | 每局一次：作废可以当作「不能被作废」打出 |

工作量最大：每个角色都要平衡 + 训练机器猫；也是以后最自然的变现点（角色 / 皮肤）。

## ④ 炸毛值

- 摸到炸毛猫、没有逗猫棒：不直接出局，而是**炸毛一格**（头像上一根竖起的毛），炸毛猫由他塞回牌堆；满两格才出局。
- 逗猫棒照旧：摸到时用掉、不涨格子。
- 以后可以先当一条百变规则「顺毛」试手感，再决定要不要单独成模式。

待定：满格是 2 还是 3；炸毛猫数量要不要少一只（不然局会拖长）。
