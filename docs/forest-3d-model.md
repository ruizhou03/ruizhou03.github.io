# Forest 三维田地模型

## 目标

Forest 的单树预览、专注成长和「我的森林」必须使用同一个世界坐标与同一套相机。树根是否落在土面由数据和投影保证，不再依赖蒙版、阴影或逐页面调整 `bottom`。

## 持久坐标

每棵树保存 `position3d`：

```js
{
  space: 'greenhouse-bed-v1',
  version: 2,
  x: 0,      // 左右，[-1, 1]
  y: 0,      // 相对土面高度；正常种植固定为 0
  z: 0.6,    // 前后，[0, 1]，0 为远处，1 为近处
  seed: 314159
}
```

`u=(x+1)/2`、`v=z` 仅保留为旧调用方与调试工具的兼容别名。v2 的事实源是 `x/y/z`。

## 相机与投影

场景标定记录背景图尺寸、远端与近端土面纵坐标、可种植宽度曲线、透视缩放和垂直比例。

对世界坐标 `(x,y,z)`：

1. `d = z ^ depthPower`
2. `halfWidth = a + b*d + c*d^2`
3. `groundY = lerp(yBack, yFront, d)`
4. `assetX = centerX + x*halfWidth`
5. `assetY = groundY - y*verticalScale*perspectiveScale`
6. 按背景图的真实相机变换投到当前视口

正常树的 `y=0`，所以投影根点恒等于 `groundY`。树的透明素材使用实测根部锚点；单树素材当前为 91.5%。素材增长只围绕根点放大，根点不移动。

桌面和手机不保存不同位置。响应式只改变相机和 billboard 的像素尺寸；移动端用完整宽幅全景比例展示同一块田，避免 `cover` 裁掉边缘世界坐标。

## 树模型与成长

树是始终朝向相机的 billboard，但位置、地面接触、世界高度、根区和树冠包围体在三维模型中计算：

- `heightWorld`：树种基础高度乘成长阶段；
- `footprintX / footprintZ`：土面根区椭圆；
- `anchorX / anchorY`：透明素材的根部像素锚点；
- `growthScale(progress)`：平滑成长比例，只改尺寸；
- `tierScale(tier)`：幼苗、成树、大树、巨树的体量。

## 分配、碰撞与遮挡

新树用树 ID 派生稳定 seed，再用 Halton 低差异序列生成候选位置。因此相同数据在刷新、设备切换和重新渲染后仍得到相同结果。

候选位置依次通过：

1. 内缩后的椭圆土面边界；边界会扣除该树根区半径，树干不能落在苔藓圈或石沿上；
2. 根区椭圆硬碰撞；
3. 屏幕树冠包围体；同深度严重重叠为硬冲突，不同深度允许有限遮挡；
4. 边缘余量、根区净空、中心平衡和树冠惩罚综合评分。

渲染按 `z` 的投影深度从远到近排序。近树自然盖住远树；同一深度用稳定 seed 打破并列，不会每次刷新跳层。

## 拖动与排序

拖动把指针屏幕坐标经过相机逆投影还原为土面 `(x,0,z)`，再执行与自动分配完全相同的根区和树冠校验。非法位置只显示预览，不写入存档。键盘移动也走同一条校验链。

按时间或专注时长排序只生成临时三维布局，不覆盖用户的手动位置；切回自由排列后恢复原 `position3d`。

## 迁移

- 已有 v2 `x/y/z`：规范化后原位保留；
- v1 `u/v`：转换为 `x=2u-1, y=0, z=v`，屏幕位置不变；
- 旧 `cell` 或 `row/col`：按原列、原行映射到田地世界坐标，保留左到右、后到前关系；
- 重复或碰撞的旧位置：保留记录本身，用确定性候选寻找最近合法区域；
- 已落在旧矩形边角或石沿上的位置：确定性迁回椭圆土面；
- 树 ID、任务、时间、时长、树种、成功状态和专注流水不改写。

## 密度策略

田地有 `full / compact / overview / dense` 四档相机体量。密度升高时只缩小 billboard 与碰撞包围体，不改变已保存的世界坐标。当前验收上限为 100 棵：必须根区零硬碰撞、全部 `y=0`、无画框裁切，并在 1.5 秒内完成确定性分配。

## 验收边界

自动测试覆盖：

- 世界坐标、土面与垂直投影；
- 正逆投影在桌面、手机和平板视口的往返；
- 根区硬碰撞与树冠软遮挡；
- 确定性分配、远近缩放和绘制顺序；
- 两代旧坐标迁移；
- 成长时根坐标不变；
- 100 棵密度和时间上限。

真实页面验收另检查 40/100 棵桌面田地、390px 手机全景、四个树种从预览进入专注后的同一 `x/y/z`，以及刷新与排序后手动位置不漂移。
