# 百变小咪 · 偷牌时别家手牌扇的统一规则

> 2026-11-22 定稿草案（待用户逐格批准）。代码：`assets/js/games/zhamao.js` 里的 `fanGeom` / `fanRects` / `fanSpot` / `startWander`；样式：`assets/css/zhamao.css` 的 `.zm-steal-fan`、`.zm-steal-card`。

被别人偷牌（两张一对、点名）时，被偷那家扣着的手牌在他头像旁边摊成一小扇，红光在牌之间游走，点中一张往上冒、飞走。这份文档规定这把扇子**长什么样**、**摆在哪**、**放不下怎么办**。

## 0. 用户已经否掉的方向（别再提）

- **竖着摊**（整把转 90°、牌顶朝桌心）——「太丑」「圆心绕着他自己，很诡异」。扇子永远横着摊。
- **整桌蒙遮罩**、**把牌搬到桌心**（2026-11-19 否）。
- **换成真正的圆弧**（试过，不好看）。形状以线上原来那把为准。
- **缩得很小**（9 人局边上那家缩到六成，「太丑陋」）。下限 0.78。
- **牌堆跟着被偷的人挪开让位**（2026-11-23 否）。牌堆位置写死。

## 1. 扇子的形状（按张数分档）

牌宽 `w = 牌堆牌宽 × 0.6 × k`（`k` 是缩放，正常 1）。第 `i` 张（`off = i − (n−1)/2`）：横向错开 `off × step`，往下沉 `|off| × drop`，转 `off × ang` 度。

| 张数 | 牌距 step | 每张角度 ang | 下沉 drop | 说明 |
|---|---|---|---|---|
| 1 | — | 0 | 0 | 一张端正放着，红光直接停在它上面 |
| 2–5 | 0.5w | min(8°, 30°/n) | 2.5px | 越多越宽，和线上一模一样 |
| 6–9 | 2.6w/n | 30°/n | 2.5px | 整把宽度基本封顶（约 3.6w），越多越密；和线上一模一样 |
| 10–12 | 2.6w/n | 30°/n | 抛物线 | 两头下沉改成平滑的弧 y = D·(off/offMax)²，D = 半宽 × tan(最外那张角度)，封顶 11px（用户 11-24：牌多了成 V 字不像弧） |
| 13–20 | max(2.6w/n, 0.15w) | 30°/n | 抛物线 | 牌缝至少 0.15w（约 5px），不再挤成一块；下沉同上 |

手牌最多 20 张；20 张时整把约 4.2w 宽、2.0w 高（手机上约 150×75px）。

被点中的那张往上冒：游走时 9px，选定时 16px。**冒起来也不能碰到他自己的名字和头像**——摆位置时每张牌都按「往上多 16px」算。

## 2. 摆在哪（按顺序试，取第一个干净的）

「干净」= 下面这些一样都不压（每张牌都按冒起来 16px 算）：

1. 摸牌那摞（连牌堆下面的张数那行）、百变规则牌；
2. 别人的头像、名字、手牌数 / 扣锅 / 档位角标（四周再留 2px）；
3. 他自己的头像、名字、角标；
4. 我的手牌、摸牌 / 出牌键、顶栏（标题、工具键）；
5. 牌桌内框（左右留 10px，上下 8px）。

并且「一眼看得出是他的」：扇子正中离他（头像 + 名字那一团的中心）比离任何别人都近（至少近 8px），而且不贴着别人（4px 以内算贴着）。只是扇子边上离邻座近不算——顶排人挤时原大的扇子本来就比座位间距宽，正对着他摊开一眼就是他的；但能离邻座远一点的位置优先（小扣分）。

弃牌堆可以压一点（软障碍，只算四分之一的代价）。

候选位置，按偏好从高到低：

| 优先 | 位置 | 怎么摆 |
|---|---|---|
| ① | **名字正下方** | 扇子顶 = 名字底 + 19px（留出冒起来的 16px）；放不下可往桌心那侧错开 ¼–1 个半宽（顶边的人最多 ¼，用户 11-24：错开多了看着不在他正下方），或再往下挪 13–61px |
| ② | **头上** | 扇子底离头像（连角标）顶 6px，可左右错开 ¼–½ 个半宽（用户原话：「放他头像下面，放不下放上面」） |
| ③ | **头像朝桌心那侧**（左右两边的人） | 扇子贴着头像（连角标）外侧 6px，和头像中线对齐，可上下错开 ¼–1 个扇高 |
| ④ | 头像另一侧 | 前三种都不行才用 |

每个位置先用原大（k = 1）试，不行再试 0.92、0.85；每一档里先用正常牌距，不行再把牌叠紧到 0.8。打分 = 偏好代价 + 离他座位的距离 × 3 + 缩放代价 (1−k)×2600 + 叠紧代价 (1−q)×500——**宁可挪位置，不缩**。

## 3. 牌堆位置写死；放不下时暂压牌堆（2026-11-24 用户定方案甲）

摸牌那摞、弃牌堆、张数那行的位置**写死，不管偷谁都不挪**（用户 2026-11-23：「不要因为抽了不同的人，就让我们的牌堆位置发生对应移动」）。11-22 草案里的「牌堆让位」已否掉、代码已删。

原大到 0.85 都找不到干净位置时（方案甲）：贴着他头像**朝桌心**摊开（左右两边的人横着朝里，顶边的人往下），原大到 0.85，**暂时压在摸牌那摞上**，偷完扇子就收；这时扇子要正对着他（顶边的人不左右错开，左右两边的人上下最多错开 ¼ 个扇高）。张数那行、别人的座位、我的手牌照样不压。朝桌心那边也被挡死（极少）才哪儿都试、最后缩到 0.78。

百变模式的规则现在是铺满桌面的淡水印（`#zmFlux`），不算障碍；下面那行规则名大字算软障碍。

## 4. 各种情况怎么落（座位 × 屏幕）

| 他坐在 | 一般结果 |
|---|---|
| 顶边 | 名字正下方。横屏 7 人以上顶边那一排沉到标题下面、正下方就是牌堆：先往桌心错开 |
| 左 / 右边，离牌堆高度远（靠上或靠下那家） | 名字正下方（往桌心错开一点）或头像朝桌心那侧 |
| 左 / 右边，和牌堆同高（中间那家） | 头像朝桌心那侧 |
| 组队围桌（2v2 … 3v3v3 / 2v2v2v2） | 同上——组队只是座位按一整圈均分，规则不分模式 |

模式（经典 / 百变 / 组队 / 角色）不单独分规则：差别只在桌子中间多了什么（百变规则牌算硬障碍），都走同一套打分。

## 5. 实测矩阵

屏幕：手机竖屏 390×690、390×844、360×690；手机横屏 844×390、667×375；平板 1180×820、1133×600；怪比例 600×700、300×600；桌面 1440×860。
模式：经典 2–9 人、组队 2v2 / 3v3 / 4v4 / 2v2v2 / 3v3v3 / 2v2v2v2、百变 9 人、角色 9 人。张数：1 / 3 / 5 / 8 / 13 / 20。每个座位都摆一遍，自动量压盖。

2026-11-24 方案甲实测（10 种屏 × 16 种局 × 每个座位 × 6 种张数 = 5220 格）：5110 格干净（原大 0.85–1、不压别人、一眼看得出是谁的），602 格暂压牌堆。剩 110 格：手机竖屏 8–9 人局左下那家（挨着我，扇子中心离我更近）、360 宽竖屏和 600×700 拿到 20 张时缩到 0.78、百变 9 人局个别座位缩到 0.78。
